Пробный урок бесплатный. Знакомимся, я смотрю, что ребёнок уже умеет, и вместе решаем, что делать дальше.

# Сколько чисел от 1 до 2026
# делятся на 3 или на 7?
count = 0
for n in range(1, 2027):
    if n % 3 == 0 or n % 7 == 0:
        count += 1
print(count)
> 868 # а теперь — без компьютера

Чем занимаемся

Математика

Идём по программе и учебникам той школы, где учится ребёнок. Разбираем то, что осталось непонятным на уроке, готовимся к контрольным и экзаменам.

  • Польская программа: szkoła podstawowa, egzamin ósmoklasisty
  • Британская программа: Key Stage 3, подготовка к GCSE

Программирование

Начинаем со Scratch: ребёнок собирает свои игры и мультфильмы и заодно привыкает думать как программист. Потом переходим на Python и пишем уже настоящий код.

  • Scratch: 4–6 класс
  • Python: 6–9 класс

Олимпиадные задачи

Для тех, кому на обычных уроках скучно. Берём нестандартные задачи, учимся рассуждать и доказывать. Часть задач решаем на Python.
